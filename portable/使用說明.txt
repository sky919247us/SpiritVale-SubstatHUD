================================================================
  SpiritVale 詞條品質快篩 HUD  v1.3.0
  讓裝備與神器的隨機詞條品質一眼可見，不必逐件按 ALT 檢查
================================================================

【這個 Mod 做什麼】

  遊戲裡的裝備與神器都帶有隨機詞條，每條在一個區間內隨機
  （例如 力量 +2~3）。原本要判斷好壞，必須把滑鼠移上去、
  再按住 ALT 才看得到區間，一整包背包要一件件檢查。

  本 Mod 直接在背包格子的名稱前加上星號並上色，
  不必 hover、不必按鍵，開背包瞬間就知道哪幾件值得留。

    ★★★ 金色 = 每一條詞條都頂到區間上限
    ★★  橘色 = 75% 以上
    ★   紫色 = 50% 以上
    無標記    = 未達標（刻意不標，避免整包都是星星）

  滑鼠移上去時，道具說明開頭還會多一行：

    ★★★ 全滿   滿素質 3/3   Roll 57%


【前置需求】

  ・SpiritVale Windows 64 位元版
  ・已安裝 BepInEx 6.x（IL2CPP 版）

  如果你已經裝了「SpiritVale 繁體中文包」，BepInEx 就已經有了，
  可直接安裝本 Mod。本 Mod 與繁體中文包完全相容，不會破壞翻譯。


【安裝】

  1. 將本壓縮檔「完整解壓縮」到任意資料夾
     （請勿在壓縮檔內直接點擊執行）
  2. 完全關閉遊戲
  3. 雙擊「一鍵安裝.bat」，依畫面指示完成
  4. 啟動遊戲即生效

  安裝程式會自動從登錄檔尋找 Steam 的遊戲位置，
  找不到時會請你貼上路徑。


【移除】

  雙擊「一鍵移除.bat」即可。

  本 Mod 只新增檔案、不覆蓋任何既有檔案，
  移除後完全回到安裝前的狀態，遊戲本體與其他 Mod 都不受影響。

  萬一遊戲無法啟動且不確定原因，可編輯遊戲目錄的
  doorstop_config.ini，把 enabled = true 改成 false，
  即可一次停用所有 Mod 回到原版。


【「滿素質」與「Roll」的差別】

  這是本 Mod 最需要理解的一點。

  遊戲內部每條詞條有一個 0~100 的 roll 值，顯示的數值由它換算而來。
  但當區間很窄時（例如 2~3 只差 1），大量 roll 值會被四捨五入到
  同一個顯示值：

      roll  50  →  顯示 +3
      roll 100  →  顯示 +3      兩者看起來完全一樣

  所以會出現「肉眼看起來全滿，Roll 卻只有 60%」的情況。
  兩個數字都對，只是在講不同的事：

    滿素質 — 實際看到、實際生效的數值是否已達上限
             （預設用這個判定星級）
    Roll   — 內部稀有度。兩件都是「滿素質 3/3」時，
             Roll 較高的那件更稀有

  想改用 Roll 判定星級，在設定檔把「以顯示滿值為準」改成 false。


【設定】

  ※ 重要：設定檔不在本壓縮檔內，也不需要你手動建立。
    它會在你「安裝完、第一次啟動遊戲」時自動生成。

  調整設定的步驟：

    1. 先開一次遊戲（讓它自動生成設定檔），然後完全關閉遊戲
    2. 用記事本開啟下面這個檔案：

         <遊戲目錄>\BepInEx\config\local.spiritvale.substathud.cfg

       Steam 預設路徑通常是：

         C:\Program Files (x86)\Steam\steamapps\common\SpiritVale
             \BepInEx\config\local.spiritvale.substathud.cfg

    3. 修改後存檔，重新啟動遊戲即生效

  本壓縮檔內附了一份「設定檔範例.cfg」，
  可以先開來看有哪些選項，內容與自動生成的完全相同。
  那份只是參考，不必複製到遊戲目錄。

  [1.功能]
    背包星號標記        預設 true   在背包名稱前加 ★ 並上色
    彈窗顯示品質總評    預設 true   道具說明開頭加品質總評
    自動顯示詞條範圍    預設 false  免按 ALT 一律顯示區間

    ※ 「自動顯示詞條範圍」會與遊戲原本的「按鍵對比裝備」功能
       衝突，導致對比視窗閃爍，因此預設關閉。
       有了星號標記通常也不需要它。

  [2.分級門檻]
    以顯示滿值為準      預設 true   true 用滿素質、false 用 Roll
    三星                預設 1.00   達此比例標 ★★★
    二星                預設 0.75   達此比例標 ★★
    一星                預設 0.50   達此比例標 ★，低於此值不標記

    想讓標記更稀有，把「一星」調高（例如 0.67）即可。

  [3.診斷]
    診斷模式            預設 false  僅供除錯，平常請保持 false


【常見問題】

  Q：會不會破壞繁體中文包的翻譯？
  A：不會。標記加的是純符號（★）而非富文本標籤，翻譯 Mod 的
     字典查不到就會原樣返回。顏色走的是 TMP_Text.color 屬性，
     完全不碰文字內容。

  Q：這算作弊嗎？會不會被鎖帳號？
  A：本 Mod 是純顯示端：不修改任何數值、不送出封包、不碰存檔。
     它只是把遊戲已經算好、本來就會顯示給你看的資訊，
     換一種方式呈現。
     關於帳號問題，請見下方「關於官方立場」。

  Q：神器也支援嗎？
  A：支援。神器的詞條結構與裝備一致，判定邏輯共用。

  Q：遊戲更新後失效了？
  A：每個功能都有獨立的錯誤處理，遊戲改版時會降級而非崩潰，
     最壞情況是某個功能沒作用，不會讓遊戲開不起來。
     查看 BepInEx\LogOutput.log 搜尋 SubstatHUD 可看到細節。
